# Lab 4 — Task 2: Bank accounts

JavaFX application for working with a hierarchy of bank accounts (individual variant 2 from Lab 2).

## Run
```bash
mvn clean javafx:run
```

## Generate JavaDoc
```bash
mvn javadoc:javadoc
```
Documentation is created in `target/site/apidocs`.

## Git / GitHub
1. Open the project in IntelliJ IDEA.
2. Select **VCS → Enable Version Control Integration → Git**.
3. Add the project files and make the first commit.
4. Use **Git → GitHub → Share Project on GitHub** to publish the repository.

The `.gitignore` file excludes Maven build output and IntelliJ IDEA settings.
